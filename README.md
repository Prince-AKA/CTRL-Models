# CTRL-Models
State-space simulations, Observer architectures, 
Reduced-order control-oriented multiphysics models, 
Nonlinear control frameworks for advanced engineering systems

Currently, this is being used as a dedicated repository for all
documents, including figures, model and simulation scripts, drafts
and selected referenced documents all related to the manuscript, 
"Reduced-Order Observer-Based Control of Uncertain Nonlinear
Multiphysics Systems with Application to Electromagnetic Stress 
Regulation". It may be restructured and renamed in the future.
